# 📖 Overview

The **Employee Payslip Management System** is a web-based application developed to simplify payroll processing and payslip generation. It enables organizations to manage employee salary details and generate professional salary slips efficiently.

The system provides an intuitive interface for handling employee information, salary components, deductions, and net salary calculations while producing printable payslips.

# ✨ Features

- 👨‍💼 Employee Information Management
- 💰 Automatic Salary Calculation

- 📊 Earnings & Deductions Breakdown
- 🖨️ Printable Payslips

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/nivedrajeeshvp/employee-payslip.git
```

Move into the project directory

```bash
cd employee-payslip
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```

# 📊 Salary Calculation

The system calculates:

```
Gross Salary

      ├── Basic Pay

      └── Other Allowances

Total Deductions

Net Salary
```
