# Frontend - Employee Management System

React.js frontend for the Full-Stack Employee Management & Payslip System.

## Features
- **Dashboard View**: Real-time KPI summary cards & department distribution table.
- **Employee Directory**: Searchable, filterable list with pagination and table/grid view toggle.
- **Employee Form**: Interactive form with real-time field validation, profile photo upload preview, and error handling.
- **Payslip Generator**: Automated calculation based on attendance leaves, print support, and PDF download.
- **Dark Mode**: Seamless light/dark theme switcher with CSS variable customization.
- **Modals & Toast**: Deletion confirmation dialogs and instant status toasts.

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `build` folder.
